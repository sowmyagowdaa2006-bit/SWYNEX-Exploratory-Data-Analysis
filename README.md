# SWYNEX Data Analyst Internship – Task 2

## Task 2: Exploratory Data Analysis

This project focuses on performing Exploratory Data Analysis (EDA) using the cleaned dataset from Task 1.

## Analysis Performed

- Calculated total, average, minimum and maximum values.
- Analyzed Actual Amount by department.
- Analyzed Actual Amount by category.
- Analyzed monthly Actual Amount.
- Compared Budget Amount with Actual Amount.
- Identified high and low values.
- Created charts to visualize the findings.

## Key Insights

1. HR recorded the highest total Actual Amount among all departments.
2. Unknown had the lowest total Actual Amount among the departments.
3. Utilities recorded the highest total Actual Amount among all categories.
4. July had the highest total Actual Amount among the months.
5. Marketing had the largest positive difference between Actual Amount and Budget Amount.
